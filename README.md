## 📖 Overview & Engineering Narrative

An award-winning, high-performance developer chronicle and technical portfolio crafted for **Kumar Dhananjaya**, showcasing production-grade distributed architectures, autonomous multi-agent systems (LangChain, Model Context Protocol), and Zero-Trust cloud pipelines.

Designed around a **storytelling narrative**, the platform takes visitors on an interactive journey through 6 technical chapters—from academic research at **The University of Sydney** to 100k+ RPS zero-overselling engines and verified upstream contributions to core open-source repositories.

## ✨ Key Architectural & Design Highlights

### 🛰️ Interactive Spacecraft Orbital Flight Navigator
- **Scroll-Linked Physics Flight**: A sleek spacecraft shuttle glides along a glowing trajectory guide, tilting into motion with dynamic ion thruster exhaust particles.
- **Click-to-Warp Navigation**: Interactive warp engine that ignites into hyper-speed plasma boost flare, piloting users directly to the next narrative chapter.
- **Orbital Waypoint Beacons**: Interactive checkpoint beacons for quick sector jumps.

### 🌕 3D Luminous Celestial Environment
- **Vector-Rendered High-Fidelity Moon**: Complete with accurate lunar maria (*Oceanus Procellarum*, *Mare Serenitatis*, *Mare Imbrium*), impact craters (*Tycho*, *Copernicus*, *Kepler* with ray systems), and multi-layered glowing coronal backlights.
- **Hardware-Accelerated Falling Stars & Meteors**: 60fps HTML5 Canvas particle engine rendering diagonal shooting star streams and depth-pulsing celestial starfields.

### 📜 6-Chapter Storyline Architecture
1. **Chapter 01: The Narrative & Sydney Odyssey** — Academic rigor at The University of Sydney (Master of CS - Advanced Entry) paired with an interactive technical competencies bento matrix.
2. **Chapter 02: Flagship Systems & Architectures (0 to 100k+ RPS)** — Interactive system showcase with category filtering (AI & Multi-Agent, Distributed Systems, Cloud & Security) and an **Architectural Deep-Dive Modal**.
3. **Chapter 03: Global Open Source Footprint** — Upstream pull requests and contributions merged into production tooling:
   - **Komodor (Helm Dashboard)**: 5+ merged PRs for Kubernetes rollback algorithms and version checks.
   - **Onyx (formerly Danswer)**: GenAI enterprise search platform citation and streaming improvements.
   - **Atlassian MCP Server**: Model Context Protocol tool calling sanitization.
   - **Tiptap Editor**: Rich text engine Safari compatibility fixes.
4. **Chapter 04: Technical Deep-Dives & Publications** — Curated system design essays published across Medium and Hashnode on RAG pipeline failure modes, high-concurrency Redis Lua inventory locking, and event-driven microservices.
5. **Chapter 05: Industry Track Record** — Glowing timeline of production platforms (<150ms real-time assessment WebSockets, IoT BLE cloud bridges, Zero-Downtime deployments).
6. **Chapter 06: Transmission & Collaborative Horizons** — Instant clipboard copy for direct email contact, validated transmission form, and Sydney time zone telemetry.

### 🔊 Pure Synthesized Web Audio Design
- Zero external audio assets; leverages the browser's native **HTML5 Web Audio API** to synthesize smooth UI audio feedback (sine/triangle oscillator clicks, hovers, and harmonic chime chords) with an instant header toggle.

### 🎯 Lag-Compensated Custom Cursor & Ambient Lighting
- Spring-physics cursor with contextual state labels (`WARP`, `EXPLORE`, `CASE`, `PR`, `READ`, `PDF`) and trailing ambient radial mesh light follower.

## ⚡ Quick Start Guide

### Prerequisites
- Node.js 18.18+ or 20+
- npm or pnpm or yarn

### Installation & Local Development

1. **Clone the Repository**
   ```bash
   git clone https://github.com/KumarDhananjaya/portfolio-new.git
   cd portfolio-new
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start Development Server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for Production**
   ```bash
   npm run build
   npm run start
   ```
